# 音击抽卡模拟器

版本：1.2.0

反馈或咨询：请通过插件仓库的 Issues 反馈。

本插件由 ongeki_gacha 项目适配而来。

## 功能

- `/签到`：每日领取点数、连续签到奖励、月卡加成和非抽卡卡彩蛋；
- `/月卡`：购买、续费或查看月卡；
- `/抽卡 [常驻] [1|5|11]`：按卡池概率抽卡，并发送合成卡面图；
- `/抽卡 <池ID> <数量>`：official 模式指定当前启用中的官方卡池抽取；
- `/点数`：查看余额、连续签到、月卡与囤点状态；
- `/卡册`：查看已收集卡牌和进度；
- `/卡图 <ID>`：发送已拥有的高清卡面；
- `/卡池 [列表|下一期]`：查看当前 / 未来卡池与 UP 信息；
- `/天井 <ID>` / `/天井池 <池ID> <卡ID>` / `/天井列表`：天井状态和兑换；
- `/接任务 普通/挑战/终极 [音击/舞萌/中二]`：从真实曲库随机领取音游任务；
- `/任务列表` / `/任务完成 <任务ID>`：查看任务、随成绩照片提交完成；
- `/任务审核 <任务ID> <普通/S/SS/SSS/SSS+/拒绝>`（管理员）：审核并发放点数；
- `/终极完成 <用户> <任务ID>`（管理员）：确认终极任务完成；
- `/任务清理 [天数]`（管理员）：立即清理已结束的历史任务；
- `/绑定QQ <QQ号>`：把当前内部 ID 与数字 QQ 绑定，合并重复玩家数据；
- `/概率`：查看当前权重与保底规则；
- `/奖励 @用户 <点数> [备注]`：管理员发放点数；
- `/规则` / `/帮助`：完整玩法和命令说明。

随机任务默认从音击、舞萌 DX、中二节奏三游戏全量曲库混合随机。普通任务任意难度；
挑战任务会随机选出至少有一张 10 级或以上谱面的歌曲，并选取该曲中达到门槛的最低
真实谱面（例如舞萌 DX 的 `EXPERT DX 10`），要求该谱面或以上取得 S；不会强制选择
曲目最高难度。终极任务从谱面定数达到 14.7 或以上的超高难曲随机，要求 SSS+；
这里的 14.7 是内部定数阈值（≥14.7），不是“14 级+”。任务提交后由管理员人工审核发点。
任务日期与重置统一按国际时间 UTC，曲绘或任务卡生成失败时会自动回退文字模式。

## 安装

把整个 `astrbot_plugin_ongeki_gacha` 目录放到
`<ASTRBOT_ROOT>\data\plugins\`，然后在 WebUI「插件管理」中加载 / 重载插件。

支持 OneBot（`aiocqhttp`）和 QQ 官方机器人（`qq_official`）。QQ 官方适配器
只提供内部 openid，不使用数字 QQ 识别用户；请先用 `/绑定QQ <QQ号>` 建立关联，
随机任务等功能需要完成绑定后才能使用。

插件安装时会自动安装 `requirements.txt` 中的依赖。首次加载会读取
`assets/card_data` 下的卡牌 JSON 和 PNG；本地开发副本保留了从 ONGEKI
素材同步的完整卡面（约 2.5GB），但发布仓库和插件发布包不附带卡面 PNG。
卡面的来源、获取方式和版权说明见
[CARD_ARTWORK_SOURCES.md](CARD_ARTWORK_SOURCES.md)。

插件默认按照历史官方 CARDMAKER 卡池每 15 天轮换，并应用卡池内 UP 权重；
活动池按活动日期混入当期版本已有全部 R/SR/SSR 基础卡，再叠加官方 UP 与天井
选择卡。轮替起点会持久化到插件数据库，重启后继续原位置，不会回到第一期。
官方公告未标注 UP 时，会显示 `UP 卡：0 张`，但这不代表池中没有候选，抽卡仍会
使用当期版本已有基础卡。当前官方排表只包含已抓取到的 63 个公告池，2023～2026 年
仍有大量日常池缺失；official 模式按「几月几日」匹配已收录池的同期排期，
忽略年份，适合作为历史卡池的模拟入口，暂不能视为完整官方时间线。
非抽卡来源卡不进入抽卡池，每日签到时按配置概率随机掉落，
并发送对应卡面图。

抽卡结果图底部带 RinNET 风格的卡牌 ID 与卡号信息条；`/卡图` 只发送原始高清卡面，
不带该信息条。奖励采用“日常小额 + 7 天/15 天周期大额 + 月度加成 + 囤点档位
（默认每 60 天重置）”的结构，适合长期签到和攒够点数后再抽。

任务由用户提交成绩照片后等待管理员人工审核；已审核、已过期、已重置记录默认保留
30 天，随后自动清理，管理员也可用 `/任务清理 [天数]` 立即清理；待审核任务不会被
自动清理。

## 配置

配置面板由 `_conf_schema.json` 生成，落盘到
`<ASTRBOT_ROOT>\data\config\astrbot_plugin_ongeki_gacha_config.json`。

| 分组 | 说明 |
| --- | --- |
| 素材路径 | 卡面目录与卡牌 JSON，可改为外部绝对路径 |
| 概率权重 | R/SR/SSR 权重、UP 倍率、轮替模式与间隔 |
| 点数 | 抽卡消耗、签到奖励、连续签到与囤点档位 |
| 月卡 | 价格、有效期、每日加成与半价五连次数 |
| 随机任务 | 每日次数、挑战/终极难度门槛、各档奖励、曲库地址与历史保留天数 |
| 管理员 | 可使用 `/奖励` 的列表；QQ 官方适配器填内部 ID（openid），也可绑定数字 QQ |

运行数据（SQLite 数据库、抽卡临时图）保存在插件数据目录
`data/plugin_data/astrbot_plugin_ongeki_gacha/`，不会写入插件目录。

## 卡牌素材

- `assets/card_data/card_info_merged.json`：卡牌元数据；
- `assets/card_data/gacha_pools.json`：官方卡池排表；
- `assets/card_data/ui_card_*.png`：本地高清卡面；
- `assets/ui/`：抽卡结果图使用的字体与 UI 贴图。

卡面 PNG 已被 `.gitignore` 忽略，发布 / 同步仓库时不会携带；本地开发环境
保留完整素材即可。`sync_card_data.py --check` 可校验素材完整性。
如需自行取得和校验卡面，请阅读
[CARD_ARTWORK_SOURCES.md](CARD_ARTWORK_SOURCES.md)。
